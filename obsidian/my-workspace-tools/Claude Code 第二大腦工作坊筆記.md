# Claude Code 第二大腦工作坊 — 重點筆記

> 主講：林穎俊（中山國小）
> 來源：https://gatelynch.github.io/claude-code-second-brain-workshop/
> 核心一句話：**你不是在學會操作 Claude Code，而是在建立一個能和 AI 一起思考的工作環境。**

## 一、觀念篇：Claude Code 是什麼（Step 1–4）
- **不是聊天 AI**：聊天 AI 是「一問一答」；Claude Code 是「在你電腦上幫你做事的 AI 代理人」。
- 它能：讀寫/整理資料夾、讀規則檔、建立修改檔案、串接 App。
- 三大關鍵能力：
  - **CLAUDE.md**：跨對話被記住的規則
  - **Skills**：把專業流程變成穩定可重複的工作流
  - 串接各種工具
- 最適合的場景＝**結構化文字工作**（文章、教案、會議記錄、簡報、專案資料），不只是寫程式。

## 二、安裝與環境（Step 5–14）
- **安裝**：到 Anthropic 官網 + VS Code 官網安裝（公認最難的一步，依官方最新文件操作）。
- **範例檔**：`git clone https://github.com/gatelynch/llm-knowledge-base.git`（或下載 ZIP）。
- **啟動**：`cd llm-knowledge-base` → 輸入 `claude`。⚠️ Claude Code 只在「啟動所在的資料夾」裡工作。
- **工作畫面建議**：左＝檔案總管、右＝Claude Code、中＝筆記/程式碼（別讓 AI 單獨運作，要搭配看檔案）。
- **互動技巧**：`@` 引用檔案、↑ 叫回上一句、`Shift+Tab` 切換模式。
- **常用指令**：

  | 指令 | 作用 |
  |---|---|
  | `/init` | 依資料夾結構自動生成 CLAUDE.md |
  | `/clear` | 清空當前對話，避免主題混淆 |
  | `/context` | 即時看 context window 用量 |
  | `/model` | 切換模型 |
  | `/rewind` | 倒退 |

## 三、知識系統核心（Step 15–26）
- **Markdown 是 Agent 的母語**：三個核心符號 `# 標題`、`- 清單`、`**粗體**`；好儲存、可搜尋、可版控、AI 易讀。
- **CLAUDE.md 是給 AI 的使用說明書**：告訴 AI 你是誰、怎麼工作、資料放哪、限制、品質標準。
  - 四原則：**精簡、依錯誤迭代、模組化、跟 Claude 一起寫**（用 `/init-llm` 協助）。
- **讓 AI 知道你是誰**：寫下身分、工作型態、偏好、文風、常見產出。
- **匯入資料**：用 pandoc / markitdown / `/convert-to-md` 把 EPUB、PDF、DOCX、JSON 轉成 Markdown。
- **不要什麼都編譯**：備份範圍廣、編譯要精選；舊臉書貼文、AI 生成內容、過時想法要謹慎。
- **標註來源**：AI 生成／網路蒐集／自己寫，避免無來源內容混進你的作品。
- **🗂 四層資料夾架構**：
  - `raw` 原始素材
  - `wiki` 編譯後的知識
  - `brainstorming` 思考與探索
  - `artifacts` 對外產出
- **第二大腦 ≠ 資料庫**：重點不是存全部，而是讓重要資料能重新參與思考。
- **Git 是時光機**：記錄改了什麼、何時改、怎麼還原（不必學工程級 Git）。
- **Evaluation／Context Engineering**：AI 需要明確品質標準；用資料夾層級、摘要、索引、命名規則降低 AI 認知負荷。

## 四、Skills 篇（Step 27–33）
- **Skill 是什麼**：把重複任務變成可執行流程（寫下步驟、規則、品質標準）。
- **Skill 不是越多越好**：只為真正重複的需求建，過多會造成混亂。
- 兩種類型：
  - **工作流 Skill（新手起點）**：整理會議記錄、潤稿、轉 Markdown、課程點子轉簡報⋯⋯重點是把固定步驟跑順。
  - **領域知識 Skill（進階）**：課程設計審查、論點評估、SDD/TDD、研究摘要評估⋯⋯包含判斷框架。
- 範例 Skill：**`ask-me`**＝請 AI 先一次問一個問題、問清楚再動工。
- **做自己的 Skill**：用 `/skill-creator`，整合第二大腦系統 + 評估標準，完成第一份 SKILL.md。

## 五、收尾（Step 34–36）
- **完成檢核**：懂 Claude Code 概念 ✓ 會用基本指令 ✓ 建好 CLAUDE.md ✓ 建立第二大腦 ✓ 寫出 Skill 草稿 ✓
- **下一步**：別一次匯入全部，先跑一個工作流；可嘗試匯入 Gmail/手機筆記、分析資料、自動抓取內容。
- **心法**：第二大腦是「用出來」的，不是一次設定完就好。
