## 🔥 最近做到哪（2026-06-01）

**收進新工具 `tools/video-kit/`（fork 自 mathruffian-dot/claude-code-video-kit）**

- 給 Claude Code 用的「三類影片製作範本」：活動紀錄(60–180s) / 教學(4–8min) / 社群科普(2–3min)
- pipeline 跟我們台日論壇那套同路數，但更成熟：`index.html(?render=true)` → Playwright 錄 webm → Edge-TTS 旁白 → ffmpeg mux 成 final.mp4
- **做影片時讀 `tools/video-kit/CLAUDE.md` 進流程**。鐵律：先寫 `SCRIPT.md`+`DESIGN.md` 給我審、說「go」才動工
- 最值錢的是 `GOTCHAS.md`，把 Windows/中文/GDrive 的雷系統化（跟我們台日論壇踩過的高度重疊）：
  - ffmpeg mux **必加 `-map 0:v:0 -map 1:a:0`** 否則 webm 空白音軌會蓋掉配音→無聲
  - ffmpeg 淡出用 `st`（秒）不是 `ss`（採樣點）
  - Playwright/node_modules 一律裝 `%TEMP%\cvs-render`，避開 GDrive + 中文路徑
  - 錄影用 `?render=true` 隱藏點擊遮罩→開頭乾淨無殘影
  - 音畫對齊：index.html / render.py / record.cjs 三處時長必須一致
  - `PYTHONUTF8=1` 避 CP950 崩潰；Python 輸出路徑用 `__file__` 不靠 cwd
- ⚠️ 注意：純 CSS/JS 管線在 Node 24 可錄；若用任何 CLI 渲染器需降 Node 20 LTS

5. **Windows+GDrive 踩雷（重要）**：
   - 逐格 PNG 一律寫**本機暫存** `%TEMP%\tjforum_kv`，**不要寫 Google Drive**（在 Drive 上 `fs.rmSync(recursive)` 會讓 Node 崩潰 exit 127）
   - `file://` 中文路徑要用 `pathToFileURL` 編碼；puppeteer headless 載 Google Fonts 用 `waitUntil:'load'`+字型逾時保護
   - `background-clip:text` + 子 span `clip-path` 會讓標題隱形 → 標題改實色、金光用疊字遮罩層
   - **git `index.lock` 殘留**會讓索引誤判「全部刪除」→ `rm .git/index.lock && git reset` 即可救回（檔案沒事）
