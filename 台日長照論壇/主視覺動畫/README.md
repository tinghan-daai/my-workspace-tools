# 2026臺中長照台日論壇 — 主視覺動態循環

主視覺定稿改成「文字依序動畫進場 → 停留 → 淡出 → 無縫循環」的動態版，給現場大螢幕循環播放用。

## 怎麼播放
1. 用瀏覽器（Chrome/Edge）打開 `index.html`
2. 按 **F11** 進入全螢幕
3. 畫面會自動等比縮放鋪滿螢幕，並無限循環（每圈 14 秒）

> 字型用 Google Fonts 的 Noto Sans TC；現場若**沒網路**會自動退回 Windows 內建「微軟正黑體」，外觀差異很小。要保險可先在有網路時開過一次讓字型快取。

## 檔案
- `index.html` — 動畫主程式（純前端，免安裝）
- `bg-clean.jpg` — 已用 AI 修圖把左側文字去掉的乾淨底圖（動畫文字疊在上面）
- `bg-original.jpg` — 原定稿（僅校位用）

## 要微調
打開 `index.html`：
- **循環長度 / 停留時間**：最上方 JS 的 `const T = 14000`、`OUT_START`
- **各行進場時間**：底部「進場時序表」區塊的 `animate(...)` 呼叫
- **文字位置 / 字級 / 顏色**：`<style>` 內 `:root` 變數與各 `#id` 規則（座標以 1920×1080 為基準）
- **校位模式**：網址加 `?align=1`，會半透明疊出原稿方便對位
