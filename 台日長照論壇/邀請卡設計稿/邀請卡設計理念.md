# 晴藍禮序

「晴藍禮序」以臺中晴空、城市地景與長照論壇的正式邀請感為核心。它不再用滿版宣傳海報的高聲量，而是把主視覺中的藍天、金線、城市建築與深藍識別收束成一張有禮、有秩序、可被正式送出的邀請卡。空間上保留大面積呼吸感，讓賓客第一眼先感到莊重與清朗，再讀到邀請資訊。

色彩以定稿主視覺的深海軍藍、天空藍與典禮金為主軸，輔以溫潤白底承載文字。金色不是裝飾用亮點，而是禮節線索：分隔、引導、收邊、標示層級。最後作品需呈現經過反覆校正的比例與留白，像是由熟悉公部門正式文宣與高階活動識別的設計者，以 painstaking attention 完成的成品。

構圖採「景觀作為信任背景、文字作為正式邀請」的邏輯。建築與天際線保留在視覺場域中，暗示臺中在地與國際論壇場景；左側文字區則像請柬內頁，將邀請語、主題、時間地點依序放置。所有線條、曲線、陰影與字距都必須精準，讓整體看起來是 meticulously crafted，而非單純把主視覺裁切貼上。

文字在此設計中只保留必要資訊：活動名稱、主題、邀請語、日期、地點、主協辦單位。字體需兼具宋體的典禮感與黑體的資訊清晰度，層級穩定，避免過多段落。最終邀請卡應有 master-level execution 的細緻度：邊界乾淨、視覺焦點明確、可直接交給長官審閱，也可後續轉成印刷或電子邀請版本。
